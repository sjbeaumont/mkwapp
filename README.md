# mkwapp
Make web apps made simple

> [!IMPORTANT]
> You must be using the Chromium browser for these web apps

> [!WARNING]
> This was a very basic programme I made to solve an issue, it is unlikely to be maintained; pull requests, and issues will still be responded to.

<br> Run this command to make a new web app:<br>
```mkwapp https://netflix.com```

That would make an app for Netflix. To remove said app:<br>
```mkwapp -r netflix```
